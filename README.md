# CraftEngineSleep Only Support 1.21.1

Adds bed behavior to CraftEngine furniture.

## How to build

```bash
./gradlew build
```

## How to use

1.  Download the latest release of `CraftEngineSleep-*.jar` from the [**GitHub Releases**](https://github.com/Rosaaalfi/CraftEngineAddon/releases) page.
2.  Ensure you have CraftEngine installed on your server.
3.  Copy `CraftEngineSleep-*.jar` to your `plugins` folder.
4.  Restart your server.

## Features

*   **Working Bed Furniture**: Allows players to right-click and sleep on custom CraftEngine furniture beds.
*   **Vanilla Sleep Mechanics**: Triggers standard Minecraft sleep behavior, including skipping the night and resetting phantom spawn timers.
*   **Directional Placement**: Supports multi-part bed furniture with accurate facing rotation depending on player orientation.
